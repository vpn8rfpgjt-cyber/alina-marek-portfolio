# Alina Marek — portfolio / online CV

To jest gotowy, statyczny prototyp strony portfolio przygotowany na bazie Twojego CV i inspiracji stroną Włącz Socjale.

## Co jest w środku
- `index.html` — cała treść strony
- `style.css` — wygląd, responsywność i animacje
- `script.js` — lekkie efekty interakcji
- `assets/alina-marek.jpg` — zdjęcie z CV
- `assets/Alina-Marek-CV.pdf` — CV jako PDF
- `robots.txt` — ustawione na brak indeksowania przez wyszukiwarki

## Najważniejsze
`noindex` oznacza, że strona ma nie pojawiać się w wyszukiwarce. Nie oznacza to jednak prawdziwej prywatności — jeśli ktoś zna adres, może wejść na stronę.

## Publikacja na GitHub Pages
1. Załóż konto na GitHub.
2. Utwórz repozytorium, np. `alina-marek-portfolio`.
3. Wrzuć wszystkie pliki z tego folderu.
4. Wejdź w Settings → Pages.
5. Włącz publikację z gałęzi `main`.
6. GitHub nada stronie adres `https://TWOJ_LOGIN.github.io/alina-marek-portfolio/`.

## Własna domena
GitHub Pages obsługuje własne domeny. Po zakupie domeny ustawiasz ją w Settings → Pages → Custom domain i dodajesz odpowiednie rekordy DNS u rejestratora.

## Co jeszcze warto dopracować
- podmienić cztery przykładowe kafelki portfolio na Twoje prawdziwe realizacje;
- dodać linki do reklam, rolek, grafik i stron;
- dodać dokładniejsze opisy projektów i — jeśli masz — wyniki kampanii;
- ewentualnie dodać osobną sekcję „Narzędzia”;
- ustalić finalną domenę, np. wariant oparty o `alinamarek`.

## Alternatywa
Jeżeli chcesz, aby strona była naprawdę chroniona hasłem, lepszym wyborem będzie Framer. Wtedy możemy zachować ten sam projekt wizualny, ale włączyć password protection.
