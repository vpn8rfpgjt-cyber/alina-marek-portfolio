PORTFOLIO ALINA — POPRAWIONA WERSJA

Wgraj wszystkie pliki z tego folderu (index.html, style.css, script.js oraz cały folder assets) na Netlify.

Zmiany: nowa typografia inspirowana CV, kafelki O mnie, hasło, uproszczone projekty, rozwinięte doświadczenie, usunięte kompetencje, zmieniony kontakt, animacja podpisu lokalizacji.

UWAGA: CV używa fontów Juana / Cerebri Sans / TT Norms Pro. Nie są dołączone, ponieważ są licencjonowane; wykorzystano podobne DM Serif Display i DM Sans.

UWAGA: Brak oryginalnych zdjęć bez tła. Obrazy w sekcjach doświadczenia i kontaktu mają miękkie maskowanie krawędzi, ale tło zdjęć nie jest naprawdę usunięte.

Zdjęcie główne delikatnie wyostrzono i powiększono, ale nie można odzyskać detali, których nie ma w źródle. Najlepszy efekt da plik oryginalny o większej rozdzielczości.

Wersja 3: przywrócone języki i dodane narzędzia. Fotografie nadal wymagają wycięcia tła z oryginalnych plików.
